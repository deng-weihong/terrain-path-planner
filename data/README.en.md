# Data

[简体中文](README.md) | [English](README.en.md)

Public examples are generated by `src/terrain_planner/datasets.py`:

- `obstacles`: a 24 x 12 m traversable region with two alternating gaps and a detour route.
- `zigzag`: flat ground of the same size with a route containing repeated heading changes.

Optional recorded maps belong in `local/site-map/`, containing `manifest.json`, a little-endian int32 XYZ map, and a reference route. The `local/` directory is excluded from version control and source archives.

Set `PATH_PLANNER_DATA_DIR` to load a map from another directory. See [Data Formats and API](../docs/en/data-format.md) for encoding and elevation conventions.
