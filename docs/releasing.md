# 源码整理与发布

[简体中文](releasing.md) | [English](en/releasing.md)

## 当前状态

项目仓库为 <https://github.com/deng-weihong/terrain-path-planner>，包含独立 Python / C++ 实现、三维可视化、测试和中英文文档。中文为默认文档。

项目采用根目录 [MIT 许可证](../LICENSE)。源码归档包含该许可证、依赖声明和 C++ 上游版权说明；依赖保留其各自许可证。发布二进制时一并保留相应授权声明。

## 生成源码快照

```bash
npm run package:source
```

生成 `releases/terrain-path-planner-0.1.0-source.tar.gz` 和 SHA-256 文件。脚本只归档显式允许的源码、文档、示例、配置和测试；不需要当前目录已经有 Git 仓库。

归档不包含：

- `data/local/` 中的现场地图与轨迹。
- Python 虚拟环境、Node 依赖和缓存。
- 编译输出、测试截图、运行日志与临时任务结果。
- 外层机器人工作区的其他模块、配置和凭据。

公开示例由代码生成，解压后不需要私有地图也能运行。项目自己的原理文档和经过挑选的界面预览图可以归档。

## 发布前验证

1. 在解压后的独立目录安装依赖，构建 C++、运行 CTest、Python / C++ 交叉回归、最小示例和前端构建。
2. 运行浏览器检查，查看桌面与手机截图，检查地图、路线与交互。
3. 对照算法文档确认当前实现和限制，验证独立 C++ 库、CLI 和可视化引擎选择。
4. 确认 `LICENSE`、代码来源、依赖与发布版本一致。
5. 核对仓库地址和待提交内容，再推送与创建版本。

Git 仓库使用 `main` 分支；中文文档保留在默认路径，英文首页为 `README.en.md`，详细英文文档位于 `docs/en/`。发布时两种语言一起核验，避免示例和约束说明不一致。
