# 算法原理

[简体中文](algorithm.md) | [English](en/algorithm.md)

本文对应 `corridor-shortcut-bspline-v3`。目标是减少整条路线的反复摆动和多余绕行，同时保留起终点、通行支撑、局部地形和边距约束。它是图搜索与连续曲线优化的组合。

Python 和 C++ 实现共享本节的数据含义和校验规则。下文的 SciPy 调用说明 Python 数值实现；C++ 使用 Eigen、LBFGSpp 和原生自然平滑样条实现相同步骤，详见 [C++ 数值实现](cpp.md)。

## 1. 地图和坐标

输入是可通行地面体素的整数索引 `(ix, iy, iz)`，而不是所有障碍物的占用点。分辨率为 `r` 时，体素中心为：

```text
x = (ix + 0.5) * r
y = (iy + 0.5) * r
z = (iz + 0.5) * r
```

反向转换使用 `floor(coordinate / r)`，负坐标也遵守同一规则。每个 XY 列保留独立的高度集合，同一 XY 可以有多个可通行 Z 层。

搜路保留 XYZ 图。平滑另建 XY 投影掩码与距离场，并用高度列校验地面支撑。投影把同一 XY 的多层合在一起，因此投影边距不能表示完整三维净空。

## 2. 三维可通行图

图节点是地面体素中心，边表示允许的地面邻接或台阶过渡。主要默认规则为：

| 规则 | 默认值或处理 |
| --- | --- |
| 普通地面邻接半径 | 0.16 m |
| 普通地面高程容差 | 0.04 m |
| 最大坡度 | 25° |
| 台阶高度范围 | 0.05–0.20 m |
| 台阶最大水平间隔 | 0.30 m |
| 最小连通分量 | 3 个节点 |
| 普通对角邻接 | 需要两个正交桥接位置支撑 |

规则一起决定边是否存在，不能单凭两点欧氏距离近就连边。不同高度层之间只有存在有效邻接或台阶过渡时才能连通。

搜索前预处理邻接、边界特征和连通分量。地图点集与图参数共同作为缓存键；更换端点可复用图，修改地图或参数会重新构建。

可视化的规划入口使用 `exact_endpoints=True`，要求选定高程层和体素中心保持不变。不可达时返回失败，不通过把端点移动到相邻楼层解决。

## 3. 搜索代价与边界偏好

搜索同时考虑连通性与边界偏好，以及距离、垂直变化、转向和台阶代价。默认优先比较连通性相关代价，再比较物理路径代价；边距属于软偏好，不保证所有点都满足目标值。

需要区分三个概念：图中可以到达、搜索更偏好宽处、连续曲线满足密集采样校验。三者分别检查，不能互相代替。

本项目端点适配器关闭图规划器原有局部平滑，将原始图路线交给全路径优化。图模块保留的局部后处理是可选兼容能力，不是页面使用的整条曲线算法。

转向项和连通性优先级使该搜索不能承诺全图欧氏最短路径。适配器默认最多展开 250,000 个节点，预处理与搜索合计最多 60 s。

## 4. 原路线走廊与边界距离场

原始路线记作 `R(s)`，`s` 为原路线的 XY 弧长。优化曲线记作 `P(s)`。最大偏离约束按相同原始弧长参数比较：

```text
||Pxy(s) - Rxy(s)|| <= max_deviation
```

这不是输出曲线到原折线的任意最近点距离。固定参数对应关系，可以避免路线跨过无关的相邻支路，但也限制了全地图重选路线的能力。

XY 可通行掩码通过欧氏距离变换生成边界距离场 `D(x,y)`。查询使用双线性插值，梯度与插值公式保持一致，供数值优化和边距投影使用。

窄端点和固定地形处可能无法满足全局目标边距。算法先取原路线边距与目标边距的较小值，再向两侧按不超过 `0.25 m/m` 的速率恢复，形成自适应下限 `c(s)`。最终校验同时报告这个下限和全局目标的实际达成情况。

因此，“低于边距下限为 0”不代表每一点都达到目标边距。距离场也未减去机器人外形半径。

## 5. 去除多余绕行

直接对原始折线做拟合，可能保留不必要的双弯。算法先在允许偏离走廊内，从当前点尝试连接沿程最远的可见点。

每条候选直达段密集检查 XY 区域、对角桥接、高度层、明显台阶、偏离和自适应边距。通过后才替代这段绕行。台阶核心与原有待核验位置受到保护。

这个过程是沿原路线的贪心可见性缩短，不是全地图的最短路径求解。它提供更直接的目标骨架，随后再联合优化曲线。

## 6. 三次 B-Spline 全局优化

平面曲线采用三次 B-Spline：

```text
Pxy(s) = sum_i B_i,3(s) * C_i
```

`B_i,3` 为基函数，`C_i` 为控制点。控制点数量由路线长度和 `control_spacing` 决定。起终点控制点固定，内部控制点共同参与 L-BFGS-B 求解。

离散目标函数包括：

```text
J = sum ||Pxy - target||²
  + smoothness * sum ||Pxy''||²
  + length_weight * sum segment_length
  + 5000 * sum min(D(Pxy) - desired_clearance, 0)²
  + 3000 * sum min(D(Pxy) - 0.035, 0)²
  + 1000 * sum max(||Pxy - Rxy|| - 0.95 * max_deviation, 0)²
  + 150 * sum terrain_preservation_error²
```

其中 `target` 来自直达缩短后的骨架，`length_weight = 1.5 / 目标采样间隔`。二阶导项降低反复弯折，长度项减少绕行，其他项约束边距、走廊和受保护地形。

控制点使用坐标盒边界辅助限制，但曲线仍必须通过后续密集校验；软惩罚和求解器收敛本身都不是可行性证明。默认最多 220 次 L-BFGS-B 迭代。

窄端点还参考原路线约 0.5 m 范围内的进出方向约束相邻控制点，避免只修复头尾几个采样造成短距离反向弯钩。

## 7. 地面高程和边距修正

优化后的 XY 如果仍支持原始地面高度，则保留原高程；只有移动后的 XY 不再支持该高程时，才尝试匹配附近原路线允许的地面层。

允许高度范围取原路线沿程 `±max_deviation` 窗口中的最低和最高高程，再加约 0.08 m 容差。无关的上层地面不能只因 XY 投影存在就成为支撑。

超过 0.15 m 的明显过渡保留在原地形附近，超过 0.20 m 的新高差被拒绝。对角桥接位置也检查相应高度，不能借用其他楼层。

边距不足处沿距离场梯度投影退让。其他失败位置会降低局部位移，并平缓恢复到周围正常优化位移。这个阶段生成细化的目标约束，最终输出还要重新求解连续曲线。

## 8. 单条连续曲线细化

局部混回原始折线会重新产生切线跳变。最终 XY 输出由 `SciPy.make_smoothing_spline` 对整条路径统一求解，基本形式为：

```text
min_f sum_i w_i * ||f(s_i) - target_i||² + lambda * integral ||f''(s)||² ds
lambda = 0.12 * sqrt(smoothness / 6)
```

固定地形、失败位置和边距退让要求通过较高拟合权重加入同一求解。算法重复细化和校验，不通过拼入原始折线隐藏不连续。

结果的 XY 样条为 C² 连续；Z 根据地面层匹配，台阶处不承诺 C²。C² 也不等于曲率足够小，接近零速度或约束冲突仍可能产生大转角，因此另行检查最小切向速度和密集转角。

## 9. 校验与失败分类

原路线与最终曲线使用同一套密集检查，按不大于 0.025 m 的原始弧长参数间隔取样，并报告输出采样的最大实际间隔。检查包括：

- XY 是否仍在可通行投影内。
- 当前地面层是否支持该高程。
- 对角移动是否有对应高度的桥接支撑。
- 高差和明显台阶是否满足规则。
- 同参数点的原路线偏离是否超限。
- 是否低于自适应边距下限。
- 起终点是否保持。

只在位置未改变时保留原路线已有异常的分类。输出区分 `newViolationCount` 与 `inheritedViolationCount`；`validation.valid` 才表示当前采样检查全部通过。算法可以返回带失败信息的曲线供分析，调用方必须读取校验字段再决定如何使用。

原始样本错误、优化新增问题、求解未收敛、曲率过大是不同状态，不应合并为一个“规划成功”。

## 10. 指标

| 指标 | 计算约定 |
| --- | --- |
| 平面长度 | XY 折线长度 |
| 三维长度 | XYZ 折线长度，结果中独立提供 |
| 曲率 RMS / 累计转向 | 按各自路线的 0.2 m 弧长间隔统一采样 |
| 局部最大转角 / 急转采样数 | 按 0.05 m 采样，急转筛查阈值为 5° |
| 最小边距 / 目标不足占比 | 按 0.05 m 采样查询 XY 距离场 |
| 近似保留路段 | 最终 XY 距原始同参数位置小于 1 mm 的采样占比 |

急转阈值是对比指标，未按具体机器人运动学标定。曲率图分别以各自沿程距离为横轴，显示绝对曲率；显示截断只影响图形，不改变指标。

## 11. 当前适用范围

输入需要已有的可通行地面地图。本项目不负责从完整 SLAM 点云提取地面，也不实现定位、动态避障、速度规划或底盘控制。

三维可视化使用真实 XYZ，但显示能力不增加算法约束。最终曲线尚未重新通过完整 XYZ 图逐边验证，未建模机器人外形与完整三维障碍净空，也未完成实机轨迹跟踪验证。

边距和走廊冲突时，算法可能无法产生通过校验的结果。改变参数不保证所有指标单调改善，也不保证搜索与平滑组合得到全局最短路径。
